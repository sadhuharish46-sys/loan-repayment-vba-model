💰 Loan Repayment VBA Model (Case Study)

📌 Project Overview

This project develops an Excel VBA model to calculate annual loan repayments for a customer under varying interest rates over time.
The model simulates a real-world banking scenario where interest rates change across different periods.

🏦 Business Scenario
A customer (Alice) requests a loan of £100,000 and wants to repay it with fixed annual instalments until 2040.

The bank offers a variable interest structure:
6% for first 5 years
8% for next 3 years
9% thereafter

The goal is to calculate:
Fixed annual repayment
Outstanding loan balance each year
Interest and principal breakdown

🎯 Objectives
Build a dynamic repayment model
Handle changing interest rates
Automate calculations using VBA
Provide full loan amortization schedule

🛠️ Tools Used
Microsoft Excel
VBA (Visual Basic for Applications)

⚙️ Model Features

User inputs:
Loan amount
Interest rates
Loan duration

Outputs:
Annual instalment
Outstanding balance
Interest paid
Principal repaid

📊 Methodology
Loan amortization logic implemented in VBA
Iterative calculation for yearly repayments
Variable interest rates applied based on time periods

📈 Results
Accurate calculation of fixed annual instalment
Clear breakdown of loan repayment over time
Flexible model adaptable to different loan scenarios

🧠 Key Insights
Variable interest rates significantly impact repayment structure
Early years are interest-heavy
Model supports financial decision-making

⚙️ How to Use
Open the Excel file
Enable macros
Enter loan details
Run VBA script
View repayment schedule

🔧 Flexibility
The model can be adjusted for:
Different loan amounts
Different interest structures
Different repayment durations

📂 Files Included
Excel VBA Model (.xlsm)
